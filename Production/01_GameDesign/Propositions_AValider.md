# Propositions — décisions actées (12 juin 2026)

> v2.0 — tranché par Pierre, intégré au GDD v0.8 et à l'architecture v1.4. Ce document n'est plus qu'un **relevé de décisions**.

## ✅ Retenu

| Proposition | Décision / nuance de Pierre |
|---|---|
| Menu pause | oui — **abandonner = défaite** (loot conservé) |
| Écran de résumé de fin de stage | oui |
| Alerte mur | **signal sonore** retenu |
| Barres de vie des monstres | oui, avec états — mais **facilement désactivables** (risque de surcharge écran) |
| Daltonisme / lisibilité élémentaire | oui, via les **chiffres de dégâts** : icône d'élément accolée — **grande = faiblesse**, **petite + flèche bas = résistance** |
| Remapping | oui — Enhanced Input + menu de réassignation |
| Auto-pause | oui |
| Rythme des vagues | **chrono inter-vague seul** (pas d'aperçu des types) ; vague nettoyée avant la fin → la suivante part immédiatement — **zéro temps d'attente** |
| Annonce de boss | message visuel **sans arrêter le jeu** (les boss sont gros et visibles) |
| Musique dynamique | oui — **étendue au menu** : la même musique évolue selon l'écran du hub |
| Succès Steam | oui (simple à implémenter) |
| Cloud save Steam | oui |
| Statistiques | oui |
| Benchmark graphique au 1er lancement | oui (natif UE, facile) |
| Kill streak | oui — à prototyper |
| Replay du tutoriel | oui |
| Enregistrement de gameplay | pas de mode photo custom ; **Steam Game Recording** le fournit gratuitement + marqueurs Timeline aux moments forts 🔶 si simple |

## ❌ Rejeté

| Proposition | Raison de Pierre |
|---|---|
| Télégraphes d'attaque au sol | les attaques visent le mur, pas le joueur — l'animation suffit |
| Aperçu des types de la vague suivante | juste le chrono |
| Achat multiple (×5/×10) | monter niveau par niveau EST le rythme du jeu ; pouvoir monter ×100 d'un coup = économie cassée |
| Vitesse ×2 en re-clear | « ce n'est pas un idle game » |
| Mode photo | non (screenshots : outils OS/Steam) |
| Minimap | inutile, le terrain tient à l'écran |
| New Game+ | le stage infini EST la fin : survivre par le switch intelligent |
