# 01_GameDesign

Conception du jeu : documents de game design (GDD), mécaniques, équilibrage et level design.

- `Mechanics/` — description des mécaniques (déplacement par lanes type MMBN, armes, monstres, mur...)
- `Balancing/` — tableaux d'équilibrage (dégâts, PV, vagues, économie)
- `LevelDesign/` — plans d'arènes, zones de spawn, progression des niveaux
