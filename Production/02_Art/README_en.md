# 02_Art

All **source** visuals (imported .uasset files stay in `WallDefense/Content/`).

- `Concepts/` — concept art, sketches, moodboards
- `References/` — external reference images
- `SourceFiles/2D/` — 2D source files (.psd, .kra, .ase, textures before import)
- `SourceFiles/3D/` — 3D source files (.blend, .fbx, .obj before import)
- `UI/` — interface mockups and sources (menus, HUD)
