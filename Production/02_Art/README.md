# 02_Art

Tout le visuel **source** (les .uasset importés restent dans `WallDefense/Content/`).

- `Concepts/` — concept arts, croquis, moodboards
- `References/` — images de référence externes
- `SourceFiles/2D/` — fichiers sources 2D (.psd, .kra, .ase, textures avant import)
- `SourceFiles/3D/` — fichiers sources 3D (.blend, .fbx, .obj avant import)
- `UI/` — maquettes et sources des interfaces (menus, HUD)
